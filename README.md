# E-Commerce Agent Crew Locally

## 1. Create and activate env

```bash
sudo apt install python3.11
```

```bash
sudo apt install python3.11-venv
```

```bash
python3.11 -m venv agent_env
```

```bash
source agent_env/bin/activate
```

## 2. Install Packages

```bash
pip install -r requirements.txt
```
